# 灵巧手工具使用 benchmark 建设差距评估

评估日期：2026-10-30（UTC）。对象：`/data/benchmark` 当前代码、任务清单及可追溯运行记录。

## 核心判断

现阶段是**场景资产、基础运行接口与离线判定原型**，尚未形成可报告端到端工具使用成功率的 benchmark。应优先打通“初始分布 → 抓起 → 按需重抓 → 功能握持 → 实际用途结果 → 独立评分”的一条可复现链路，再扩展任务数量。

- 已注册 83 个入口：10 个基础任务、72 个扩展原型、1 个毛巾任务。扩展原型中 25 个有刚体近似判定，47 个仅有场景资产；不能把这些数目当作完成任务数。
- 既有采集汇总记录 `real_successful_episodes = 0`；本次评估不新增物理试验，未产生工具使用成功轨迹。没有有效试验分母时，成功率应为“未测”，不应写为 0%。
- 2026-10-30 11:16 UTC 的 standalone PhysX CUDA articulation smoke 已 PASS，但其范围明确排除 Isaac Sim 场景验证和任务成功。旧文档“完全没有 GPU/物理能力”的笼统表述已不适合描述全部记录。
- `functional/evaluator.py` 已有掌心系相对位姿与接触变化判定；示例契约仍未标定，现有 Isaac 适配器未输出它所需的全部观测。

## 评估范围与证据规则

区分：资产存在、代码实现、合成测试、当前版本物理运行、闭环功能成功、独立泛化评测。高一级证据不能由低一级自动推导。旧运行报告保留原时间与输入哈希，不覆盖历史记录。

本报告正在补充可复现反例、公开方法对照及逐项验收标准。完成后以配套机器可读审计与 backlog 为准。
